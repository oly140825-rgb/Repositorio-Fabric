# Microsoft Fabric - Material del Curso

Bienvenido al repositorio oficial del curso de **Microsoft Fabric**.

Este repositorio reúne los materiales, ejemplos y recursos utilizados durante las clases. Su objetivo es proporcionar un espacio centralizado para que los participantes puedan acceder al contenido, practicar con ejercicios y profundizar en los conceptos vistos a lo largo del curso.

## Objetivos del curso

Al finalizar el curso, los participantes serán capaces de:

* Comprender la arquitectura y los componentes principales de Microsoft Fabric.
* Crear y administrar espacios de trabajo (Workspaces).
* Ingerir, transformar y preparar datos utilizando Data Factory y Dataflows Gen2.
* Trabajar con Lakehouse y Warehouse para el almacenamiento de datos.
* Desarrollar procesos de ingeniería de datos mediante notebooks y Apache Spark.
* Construir modelos analíticos y visualizaciones con Power BI.
* Automatizar procesos mediante pipelines.
* Aplicar buenas prácticas de gobierno, seguridad y monitoreo.

## Contenido del repositorio


## Requisitos

Antes de comenzar se recomienda contar con:

* Una cuenta de Microsoft.
* Acceso a un entorno de Microsoft Fabric.
* Conocimientos básicos de SQL.
* Conocimientos básicos de análisis de datos.
* Visual Studio Code (opcional).
* Git instalado (opcional).

## Cómo utilizar este repositorio

1. Clonar el repositorio.
2. Revisar el material correspondiente a cada módulo.
3. Descargar los datasets necesarios.
4. Realizar los ejercicios propuestos.
5. Comparar los resultados con las soluciones disponibles.
6. Experimentar modificando los ejemplos para reforzar el aprendizaje.

## Buenas prácticas

* Mantener una copia de los notebooks antes de modificarlos.
* Trabajar con copias de los datasets originales.
* Documentar los cambios realizados durante las prácticas.
* Utilizar nombres descriptivos para los recursos creados.
* Eliminar recursos temporales una vez finalizadas las actividades.
